Engo PDF Viewer v17 - إصلاح فصل ونقل التابات
================================================

الملفات التي تم تعديلها:
- main.py
- engo_app_dialogs.py

ما تم إصلاحه:
1) فصل التاب أصبح عملية نقل حقيقية، ولم تعد تستدعي deleteLater() على DocumentTab.
   يتم الاحتفاظ بنفس كائن المستند ونقله إلى QStackedWidget الخاص بالنافذة الجديدة.
2) تنظيف مراجع السحب والمؤقت قبل نقل التاب أو إغلاقه لمنع استخدام QWidget بعد حذفه.
3) حماية paintEvent من المراجع المحذوفة، وإنهاء QPainter دائمًا باستخدام finally.
4) جعل فحص فهارس التابات آمنًا أثناء أحداث السحب والإفلات.
5) إعادة إنشاء زر الإغلاق المخصص (×) في شريط التابات بالنافذة المستقبِلة.

طريقة تطبيق التحديث:
- احتفظ بنسخة احتياطية من مجلد المشروع الحالي.
- فك ضغط هذه الحزمة فوق مجلد المشروع الحالي مع السماح باستبدال الملفات.
- شغّل البرنامج للتجربة، أو استخدم ملف البناء المعتاد لديك لإعادة إنشاء نسخة Windows.

التحقق المنفذ هنا:
- نجح python -m compileall على ملفات المشروع.
- نجحت فحوص ثابتة لمسار detach/adopt، ومنع حذف التاب أثناء النقل، وإنشاء زر الإغلاق،
  وحماية paintEvent وإنهاء QPainter.
- لم يتم تشغيل واجهة Qt أو اختبار السحب فعليًا هنا لأن بيئة التنفيذ الحالية لا تحتوي PyQt6
  ولا بيئة بناء Windows. لذلك يلزم تجربة التاب على جهاز Windows بعد تطبيق التحديث.

ملاحظة:
هذه حزمة مصدر كاملة مبنية على ملفات المشروع التي رفعتها، وليست ملف EXE جاهزًا.
